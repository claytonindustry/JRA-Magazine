Which markers survive a translator

The point of the whole thing is that a boat's name is not translated. The editor swaps each protected name for a marker before the words go to a translator, and swaps it back afterwards — which only works if the translator leaves the marker alone. Nobody has ever checked that it does. This checks it, in two different ways, in two languages.

How to run it
  1. In Chrome: right-click this page, Translate to French. Read the list below. Then do it again in Chinese — that one matters most.
  2. Every line should still contain its marker, unchanged. Line 1 is the control and should turn into Miroir or 镜子 — if it does not, the page never translated and nothing else here means anything.
  3. Then the other way: press the button further down, paste into translate.google.com, and check the same thing. The two routes are different engines and may not agree.
  4. Tell me which numbers kept their marker, for each language and each route.

What the answer tells us



  
If the digit markers survive in French but not in
  Chinese — likely, since a translator may well write 1 as 一 —
  then the marker must use a letter rather than a number, and the ones with
  letters below will say which.

  
If the fancy brackets ⟦ ⟧ are stripped but
  the plain ones survive, we change the brackets and lose nothing.

  
If nothing survives in Chinese, then
  names cannot be protected in Chinese by this route at all, and we would want to
  know that before building anything else on it.

  
If the two routes disagree, the sheet and
  the paste box are not interchangeable and the editor should push you towards
  whichever one works.
