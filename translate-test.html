Which words survive a browser translation

Eight ways of asking Chrome to leave a word alone. Every line below is ordinary English prose with the word lighthouse in it, marked up a different way each time. Translate this page and see which ones still say lighthouse.

How to run it
  1. Right-click anywhere on this page and choose Translate to…, or use the translate icon in the address bar. French or German is fine.
  2. Read down the list. Any line still showing the English word lighthouse was left alone; any line showing phare, Leuchtturm or similar was translated.
  3. Tell me the numbers that survived. That is the whole result.

8. The keeper rowed out to the lighthouse before the weather turned.

What each answer would mean

1 translated and 8 survived — the test ran properly. If that is not so, the translation did not take and nothing else below is worth reading.

3 or 4 survived — the shape Chrome stepped over in issue 300 can be reproduced without changing how a word looks. Fragile, but free. If only 4 survives, the opt-out attribute is actively unhelpful, which is worth knowing.

5 survived — depth alone is enough, and the marked words need no formatting elements at all. This is the tidiest of the tricks.

6 or 7 survived — the sturdiest answer available in the browser: the words are real, selectable, searchable text that the translator cannot reach. More machinery, and it leans on JavaScript.

Only 8 survived — there is no way to protect a phrase mid-sentence in Chrome, and owning the translation is the only route to it.
